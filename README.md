# Portfólio — Rafael Fernandes dos Santos

Portfólio profissional desenvolvido em formato de site para apresentar minha experiência, formação, competências e projetos na área de Dados, Business Intelligence, Automação e Inteligência Artificial.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Bootstrap Icons

## Funcionalidades

- Layout responsivo
- Tema claro e escuro
- Navegação entre seções
- Apresentação da experiência profissional
- Formação acadêmica
- Competências técnicas
- Projetos selecionados
- Links para LinkedIn e GitHub
- Download do currículo em PDF
