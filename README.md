# Portfólio — Rafael Fernandes dos Santos

Portfólio profissional desenvolvido em formato de site para apresentar minha experiência, formação, competências e projetos nas áreas de Dados, Business Intelligence, Automação e Inteligência Artificial.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Bootstrap Icons

## Funcionalidades

- Layout responsivo
- Tema claro e escuro
- Persistência da preferência de tema no navegador
- Navegação entre seções
- Apresentação da experiência profissional
- Formação acadêmica
- Competências técnicas
- Projetos selecionados
- Links para LinkedIn e GitHub
- Download do currículo em PDF

## Objetivo

O projeto foi desenvolvido como portfólio profissional e também como parte do meu processo de aprendizado e evolução em desenvolvimento Front-End durante o Bacharelado em Ciência da Computação.

Além da apresentação profissional, o projeto permite aplicar na prática conceitos de HTML, CSS, JavaScript, Bootstrap, responsividade e controle de temas.
